Entry for the make.fun bounty [The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9): a program that writes the GPS's one-line excuse for sending the driver down the wrong road to `/output/entry.txt`.

## The line

> The map called it a shortcut, so I believed it. Now you're at a cul-de-sac wedding and I'm the plus-one.

104 characters, one line, no trailing newline.

## Run

```sh
node main.ts
```

Writes `entry.txt` to the directory in `MAKEFUN_OUTPUT_DIR` (default `/output`). Deterministic: no network, no randomness, no clock — the same line every run.
